# 📚 AI 서재 (뤼튼 크랙 비공식 클라이언트)

뤼튼 크랙 채팅방을 한곳에서 정리·관리하는 데스크탑 클라이언트.
채팅방을 책꽂이처럼 관리하고, 검색·태그·폴더·메모, 메시지 토큰 카운터 등을 지원합니다.

⚠️ 시작 전 꼭 읽어주세요

- 이건 뤼튼 측 공식 앱이 아닌 비공식 클라이언트입니다.
- 데이터는 모두 본인 PC 에만 저장됩니다. (외부 서버 전송 없음)
- 코드 서명 인증서가 없어서 첫 실행 시 OS 가 경고를 띄웁니다. 정상이며, 아래 안내대로 우회 가능합니다.
- 뤼튼 공식 업데이트 시 일시적으로 동작이 깨질 수 있습니다.
- 본인 책임 하에 사용하시고, 사용 전 뤼튼 공식 앱에서 한 번 백업해두시는 걸 권장합니다.

---

## 🍎 Mac 설치 가이드

###⚠️ "손상되었기 때문에 열 수 없습니다" 경고 해결

macOS Sonoma (14) 이상부터 무서명 앱을 자동 차단합니다. 우회 방법:

**터미널 (Spotlight → "터미널" 검색) 열고 한 줄 입력:**

```bash
xattr -cr ~/Downloads/AI\ 서재.app
```

> 만약 앱을 다른 폴더로 옮겼으면 그 경로로 변경:
> ```bash
> xattr -cr "/실제/경로/AI 서재.app"
> ```

이 명령은 macOS 가 인터넷 다운로드 파일에 자동으로 박는 quarantine 속성을 떼어냅니다. 보안 위험은 없습니다.

### 실행
- `AI 서재.app` 더블클릭
- 또는 처음 한 번은 **우클릭 → "열기"** → 경고창에서 다시 "열기"

## 🪟 Windows 설치 가이드

### 1. AI.Setup.exe 다운로드 → 더블클릭

### 2. ⚠️ "Windows의 PC 보호" 경고 해결

무서명 앱이라 Windows SmartScreen 이 차단합니다. 우회 방법:

1. 경고창에서 **"추가 정보"** 클릭
2. 화면 하단 **"실행"** 버튼 클릭
3. 자동으로 설치되고 시작됩니다

> 코드 서명 인증서가 없어서 뜨는 경고이며, 보안 위험은 없습니다.

## 🚀 첫 실행

앱이 켜지면 **환영 화면** 이 뜹니다:

1. **🚀 뤼튼 로그인하고 시작** 버튼 클릭
2. 별도 로그인 창이 열립니다 → 크랙 계정으로 로그인
3. 로그인 완료 후 자동으로 채팅방 동기화 시작
4. 2,400+ 방의 경우 첫 동기화에 5~15초 정도 걸립니다

## 🔄 자동 업데이트

새 버전이 나오면 앱 안에 자동으로 알림이 뜹니다:
- **상단 배너** + **사이드바의 ⬆ 업데이트 버튼**

- 기존 데이터(폴더/태그/메모/백업) 그대로 유지됩니다

## ❓ 문제가 생기면

### 진단 정보 복사해서 보내주세요

앱 안에서 **`Cmd+K`** (Mac) 또는 **`Ctrl+K`** (Win) → "**앱 진단 정보**" 검색 → 클릭

→ 모달이 뜨고 진단 정보가 자동으로 채워집니다.
→ **📋 클립보드에 복사** 버튼 클릭
→ GitHub Issue에 붙여넣기

### 진단 정보에 포함되는 것
- 앱 버전, OS, Electron/Chrome 버전
- 토글 설정 (대리방지/외출모드 등 ON/OFF)
- localStorage 키 이름 + 크기 (값 X)
- 최근 에러 (메시지 + 스택)

### 절대 포함되지 않는 것 (개인정보 보호)
- ❌ API 키 / 비밀번호
- ❌ 채팅 본문 / 메시지 내용
- ❌ 이메일 / 사용자 이름
- ❌ 파일 경로 (사용자명 노출 X)

## 🛡️ 자주 묻는 질문

### Q. 안전한가요?
- 코드는 모두 공개되어 있고 (GitHub) 데이터는 본인 PC 에만 저장됩니다
- API 키는 macOS 키체인 / Windows 자격증명 관리자에 안전하게 저장
- 외부 서버로 데이터 전송 없음

### Q. 뤼튼 공식 앱이 업데이트되면?
- 일시적으로 일부 기능이 깨질 수 있습니다
- 보통 며칠 안에 대응 패치가 나옵니다 (자동 업데이트로 받음)

### Q. 데이터 백업은?
- 앱 안에서 **`Cmd+,`** (Mac) / **`Ctrl+,`** (Win) → 설정 → 백업 → JSON 파일로 export
- 다른 PC 에서 복원 시 같은 메뉴에서 import

### Q. 여러 PC 에서 같은 데이터 공유?
- 자동 동기화는 안 됩니다 (로컬 우선 정책)
- 백업 파일 export → 다른 PC 에서 import 로 수동 동기화 가능

### Q. 사용 중 앱이 느려져요
- 사이드바의 💾 버튼 색이 노란색/빨간색이면 저장공간 부담
- 클릭 → 무거운 키 확인 → 정리

### Q. 채팅방이 갱신 안 돼요
- 상단 **🔄 새로고침** 버튼 클릭
- 그래도 안 되면 도움말 → 트러블슈팅 참고
